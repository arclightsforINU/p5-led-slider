# p5.js 슬라이더로 LED 밝기 조절하기

p5.js 슬라이더 값을 Web Serial로 Arduino Uno에 보내 D9 LED의 밝기(PWM 0~255)를 조절하는 실습 기록이다.

- 글: https://arclightsforinu.github.io/p5-led-slider/
- p5.js: `web/sketch.js`
- Arduino: `led2_pwm_test/led2_pwm_test.ino`
- 연결도: `assets/p5-led-slider-breadboard.svg`
- PC 검사: `tools/p5sim/`
